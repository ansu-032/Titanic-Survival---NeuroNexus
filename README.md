# Titanic-Survival---NeuroNexus

🛳 Titanic Survival Prediction
This project uses the famous Titanic dataset to build a machine learning model that predicts whether a passenger survived the disaster. It covers the full data science pipeline, including data preprocessing, visualization, model training, and evaluation.


📂 Dataset
Source: [Kaggle Titanic Dataset](https://www.kaggle.com/datasets/brendan45774/test-file)
Features used: Sex, Age, Ticket, Pclass, Fare, Survived


🔧 Technologies & Tools
Python (Pandas, NumPy, Matplotlib, Seaborn)
Scikit-learn
Jupyter Notebook


📊 Steps Performed
Data Preprocessing
Handled missing values using KNNImputer
Encoded categorical variables (Sex, Ticket)


Exploratory Data Analysis (EDA)
Swarm plots, histograms, box plots, correlation heatmap
Analyzed survival rates by gender, class, and fare


Model Building
Trained a RandomForestClassifier
Split data into training and testing sets
Evaluated model using accuracy, confusion matrix, and classification report
